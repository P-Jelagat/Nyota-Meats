# Nyota Meats Landing Page

A responsive business landing page template designed for meat distributors, wholesalers, food suppliers, and agricultural businesses.

## Overview

Nyota Meats is a modern landing page template built with HTML, CSS, and JavaScript. The template focuses on trust, product presentation, service coverage, and lead generation through clear calls to action and business-oriented content sections.

## Features

* Responsive design for desktop, tablet, and mobile devices
* Sticky navigation bar
* Mobile-friendly navigation menu
* Hero section with call-to-action buttons
* About Us section
* Product showcase with grid layout
* Coverage & Service Areas section
* Why Choose Us section
* Customer testimonial carousel
* Interactive FAQ accordion
* Contact-focused footer
* Smooth scrolling navigation

## Built With

* HTML5
* CSS3
* Vanilla JavaScript
